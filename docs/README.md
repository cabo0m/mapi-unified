# Documentation map

Start here if you are installing MAPI for another user:

1. `INSTALLATION.md` — step-by-step Windows local, Linux local and Linux/VPS remote installation.
2. `MCP_INTEGRATION.md` — connect the MCP server, with separate Windows/Linux and local/remote paths.
3. `TROUBLESHOOTING.md` — diagnose startup, port and client-connection failures.
